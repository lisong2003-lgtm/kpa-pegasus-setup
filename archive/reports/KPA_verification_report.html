真正的问题清单

  • 阻塞MSX 3/3 全黑：bluemsx_libretro_android.so 只下载到 /sdcard/Download 和 RetroArch/cores，没装进 RA 的 app 私有目录。public/shell 路径的 .so 被 SELinux avc: denied { execute } 拒绝。BIOS（MSX.rom / MSX2.rom / Machines）已齐全，不是 BIOS 问题。
  • ROMCPS1 / dynwarjr：zip 完整（22 文件、CRC 全通过、1996-12-24 老 ROM 集），15 秒仍黑；换 fbneo 核心同样黑 → ROM 集问题，换核心无效，建议换 ROM 或从天马移除。
  • ROMSFC / 超级炸弹人4：2MB .sfc，15 秒仍只有边框；换 snes9x / snes9x2002 / snes9x2010 三个核心都黑 → 该 ROM 本身有问题，同平台另两个游戏正常。
  • 误判PS / 射雕英雄传：368MB CHD 加载慢，15 秒后正常出片头（CENTRO logo），无需处理。
  • 待确认MAME / parodius、bloodstm、hook：8 秒时停在 RAM CHECK / RAM OK 自检画面，核心已正常加载，但未验证能否自动进入游戏。
  • 历史CPS1/mercsj、NEOGEO/samuraia、NEOGEO/sonicwi 仍是 fbalpha2012 兼容问题，换 fbneo 可出画面，等用户决定是否换核心并补竖版 cfg。

滤镜 / 着色器 / 遮罩 / 满屏 / 按键

  • 滤镜：全局 video_filter = ""，未启用，无异常。
  • 着色器：video_shader_enable = true，实测 PS 启动命中 crt-easymode.slang 磁盘缓存，CRT 生效。
  • 遮罩：厂商 overlays/*_B.cfg 边框正常显示（A2600 橙边、PS 的 PLAYSTATION 竖字、SFC 的 SUPER FAMICOM）；竖版 cfg 统一 input_overlay_enable=false，符合预期。
  • 满屏/满高：多数平台画面外接矩形 95.4% × 100%（边框内满高）；GBA 100×100；CPS 系 90×100；PICO 约 62–67% 宽；PPSSPP 独立渲染 83–100%。竖版旋转后横躺，填充 87–92% 宽 × 91–100% 高。
